# Шаг 4. UI — экраны, макеты, компоненты

## 4.1. Общая структура Layout

### _Layout.cshtml

```
┌──────────────────────────────────────────────────────────────┐
│  Навигационная панель (Navbar)                                │
│  ┌─────────────────────────────────────────────────────────┐ │
│  │ Логотип  │ Dashboard │ Tickets │ [Admin ▼]  │ 👤 Профиль│ │
│  └─────────────────────────────────────────────────────────┘ │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  @RenderBody()                                               │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│  Footer: © 2026 Company | Версия 1.0                         │
└──────────────────────────────────────────────────────────────┘
```

**Элементы навигации:**
- **Dashboard** — для всех авторизованных
- **Tickets** — для всех авторизованных
- **Admin ▼** — выпадающее меню (только для Admin):
  - Пользователи
  - Продукты
  - Отделы
  - Аудит-лог
- **Профиль** — аватар/имя, выпадающее: Профиль, Сменить пароль, Выход
- **Переключатель темы** — иконка 🌙/☀️ в навбаре

### Темы (Light/Dark)
- CSS-переменные в `:root` и `[data-theme="dark"]`
- Переключение через JS: `document.documentElement.setAttribute('data-theme', ...)`
- Сохранение выбора в `localStorage`

- «Критичные» — `Priority = Critical AND Status != Closed`
- «Просроченные» — заявки старше N дней без статуса `Closed` (N из конфигурации)

## 4.10. JavaScript-скрипты

### Структура wwwroot/js/

```
wwwroot/js/
├── site.js               # Общие скрипты (тема, навбар)

└── dashboard.js          # Динамические элементы дашборда
```

### Ключевые JS-функции

```javascript
// site.js — Переключение темы
function toggleTheme() {
    const current = document.documentElement.getAttribute('data-theme');
    const next = current === 'dark' ? 'light' : 'dark';
    document.documentElement.setAttribute('data-theme', next);
    localStorage.setItem('theme', next);
}

// drag-drop-upload.js — Drag-and-drop загрузка
// - Обработка событий dragover, dragleave, drop
// - Валидация файлов (расширение, размер) на клиенте
// - Отправка через FormData + fetch API
// - Прогресс-бар загрузки
// - Отображение списка загруженных файлов перед отправкой

// comments.js — AJAX-комментарии
// - Добавление комментария без перезагрузки страницы
// - Проверка IsInternal на клиенте
// - Обновление ленты комментариев
```
