## 10.2. Матрица тестирования по ролям

### Заявитель (Applicant)

| Сценарий | Ожидаемый результат |
|----------|---------------------|
| Создать заявку | ✅ Заявка создана, номер присвоен |
| Посмотреть свои заявки | ✅ Видит только свои |
| Посмотреть чужую заявку по прямой ссылке | ❌ 403 Forbidden |
| Добавить комментарий к своей заявке | ✅ Комментарий добавлен |
| Добавить внутренний комментарий | ❌ Нет такой опции |
| Посмотреть внутренний комментарий | ❌ Не отображается |
| Закрыть заявку (статус Resolved) | ✅ Статус изменён на Closed |
| Переоткрыть заявку (статус Closed) | ✅ Статус изменён на Reopened |
| Редактировать заявку | ❌ 403 Forbidden |
| Назначить исполнителя | ❌ Нет такой опции |
| Удалить заявку | ❌ 403 Forbidden |
| Загрузить файл к своей заявке | ✅ Файл загружен |
| Скачать файл | ✅ Файл скачан |
| Удалить файл | ❌ 403 Forbidden |
| Открыть админку | ❌ 403 Forbidden |
| Экспортировать в Excel | ❌ Нет такой опции |

| Сценарий | Ожидаемый результат |

## 10.3. Валидация данных

### Клиентская валидация (jQuery Unobtrusive)

| Поле | Правило | Сообщение об ошибке |
|------|---------|---------------------|
| Title | Required, MaxLength(200) | "Заголовок обязателен" / "Макс. 200 символов" |
| Description | Required | "Описание обязательно" |
| ProductId | Required | "Выберите продукт" |
| Priority | Required | "Выберите приоритет" |
| Category | Required | "Выберите категорию" |
| Source | Required | "Выберите источник" |
| Version | MaxLength(20) | "Макс. 20 символов" |

### Серверная валидация (Data Annotations / FluentValidation)

| Правило | Описание |
|---------|----------|
| Размер файла ≤ 50 МБ | Проверяется в `AttachmentService` |
| Суммарный размер файлов ≤ 500 МБ | Проверяется перед загрузкой |
| Допустимые расширения файлов | Проверяется на клиенте и сервере |
| Номер заявки уникальный | UNIQUE constraint в БД |
| Email уникальный | UNIQUE constraint + Identity |
| Исполнитель должен иметь роль Engineer | Проверяется в `TicketService.AssignAsync` |
