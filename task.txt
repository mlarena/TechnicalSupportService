# ТЕХНИЧЕСКОЕ ЗАДАНИЕ
на разработку веб-приложения «Система управления технической поддержкой» (СУТП)

**Корневая директория проекта:** `C:\dev\TechnicalSupportService\`
**Стек:** .NET 10, ASP.NET Core MVC, EF Core 10, PostgreSQL 16+, Bootstrap 5
**Платформа:** Linux Debian (разработка на Windows)
